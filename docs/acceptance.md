
# Acceptance criteria

## General
- Works at 360px without horizontal overflow.
- Content matches content.md.
- No invented Meli+ benefits.
- Semantic HTML.
- Keyboard accessible.
- Visible focus states.
- Touch targets >= 44px where practical.

## B1
- Esencial and Total are explicit before interaction.
- Tabs update the displayed plan.
- Swipe is optional.
- Tab state updates after swipe.
- Reduced motion removes onboarding animation.

## B2
- Both plans exist in normal document flow.
- Contextual pill becomes sticky only inside plans.
- Active plan updates while scrolling.
- Pill allows jumping both directions.
- Reduced motion disables smooth scroll.
