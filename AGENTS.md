
# Project instructions

This is a UX prototype for a Mercado Libre design challenge.

Priorities:
1. UX fidelity
2. interaction fidelity
3. accessibility
4. visual polish
5. code simplicity

Read before making changes:
- docs/product.md
- docs/ux-spec.md
- docs/content.md
- docs/acceptance.md

Do not:
- invent product requirements;
- modify approved copy;
- introduce backend functionality;
- add libraries unless clearly necessary;
- over-engineer abstractions.

Shared UI between B1 and B2 should reuse components.

Target:
mobile-first at 360px.
Also sanity-check 390px and 412px.

Implement both explorations independently so they can be compared.
